# Changelog

All notable changes to the MCF Personal Finance Tracker will be documented in this file.

## [1.0.0] - 2025-03-23

### Added
- Expense entry form with amount, category, date, and optional notes
- 8 spending categories: Housing, Food, Transportation, Entertainment, Education, Healthcare, Savings, Other
- Dynamic bar chart and donut chart via Chart.js (update on every submission)
- Monthly budget setting with auto-save and real-time comparison panel
- Budget vs. Spending stats: Budget, Spent, Remaining with percentages
- Color-coded budget progress bar (green/yellow/red) with contextual messages
- Budget vs. Actual grouped bar chart
- Over-budget visual alerts (red border, red remaining amount)
- Monthly expense filtering by month
- Recent expenses list with category color dots and inline delete
- "Chat with Oliver" AI budget assistant (Anthropic API, Beta)
- 3 suggested starter prompts for Oliver
- Oliver's profile picture in chat header
- AI sparkle icon on chat button with Beta badge
- Dark/light mode toggle with localStorage persistence
- Export CSV functionality
- Save & Download PDF report with MCF branding
- Download blank printable template PDF
- Profile & Settings section (name, stored locally)
- localStorage data persistence (no account required)
- Full MCF brand identity: logo, colors, tagline, footer links
- Responsive design (mobile-first)
- Smooth animations and transitions
- All external links open in new tabs
